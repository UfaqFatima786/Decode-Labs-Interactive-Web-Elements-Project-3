# 🌐 Decode Labs – Interactive Web Elements Project 3

Welcome to **Project 3** of the Decode Labs Internship Program. This project focuses on creating an engaging and interactive webpage using **HTML, CSS, and JavaScript**. The goal is to enhance user experience by implementing dynamic web elements and interactive features.

## 🚀 Live Demo

🔗 https://interactive-web-elements.netlify.app/

## 📌 Project Overview

This project demonstrates the use of JavaScript to add interactivity to a webpage. Users can interact with various elements such as buttons, toggles, and dynamic content sections that respond instantly to user actions.

## ✨ Features

- 🎯 Interactive buttons and controls
- 🔄 Dynamic content updates
- 🎨 Modern and responsive UI design
- ⚡ Smooth user interactions
- 📱 Mobile-friendly layout
- 🖱️ Event-driven functionality using JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
